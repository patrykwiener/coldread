A part is the text under one heading; the text above the first heading is a part too, and an answer without headings is one part.
In each part, count the main points: separate reasons, causes, considerations or steps, and each item of a list. A table counts as one point, however many rows it has. A sentence that only introduces a list is not a point.
PASS if no part has more than four main points.
FAIL if any part has five or more, for example six reasons listed under one heading, or five separate reasons in an answer without headings.
