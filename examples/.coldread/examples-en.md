# Style anchors

Match the register, density and opening of these examples, not their topics.

## PR description opening

> Please approve one trade-off before merge: a new seller's first payout now waits for the KYC check, which can delay it by up to two days.
>
> The Payout API sent first payouts before the check finished, so two sellers were paid before their identity was confirmed. It now holds a seller's first payout until the check passes. Later payouts are unchanged.

Why it works: the decision and its cost come first. The cause follows with one concrete case, and every name is one the team uses daily.
